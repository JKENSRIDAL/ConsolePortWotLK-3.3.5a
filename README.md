# ConsolePort WotLK 2.2

Juega World of Warcraft **3.3.5a (Wrath of the Lich King)** con mando. Basado en ConsolePort.
Play World of Warcraft **3.3.5a (Wrath of the Lich King)** with a controller. Based on ConsolePort.

## Novedades / What's new (2.2)
- ALT como tercer modificador (8 combinaciones por botón) / ALT as a third modifier (8 combinations per button).
- Disposición "Midnight" predeterminada para mandos Xbox / "Midnight" default layout for Xbox controllers.
- Barra de acción estilo retail: arte de clase con resplandor, bordes biselados y mini-botones LT / RT / LT+RT / Retail-style action bar: class art with glow, beveled borders and LT / RT / LT+RT mini-buttons.
- Anillo de utilidad: monturas y mascotas funcionan; combinación elegible al primer inicio o con `/cpuring` / Utility ring: mounts and pets work; key combination chosen on first login or with `/cpuring`.
- Menú radial del juego (RT + A) / Radial game menu (RT + A).
- Teclado radial: Enter, Retroceso, Supr y Esc desde un teclado físico o virtual / Radial keyboard: Enter, Backspace, Delete and Esc from a physical or on-screen keyboard.

La lista completa está en `ConsolePort/WOTLK_CAMBIOS.txt` / Full list in `ConsolePort/WOTLK_CAMBIOS.txt`.

## Instalación / Installation
1. Descarga el código (**Code > Download ZIP**) o el archivo de la última versión / Download the code (**Code > Download ZIP**) or the latest release file.
2. Copia todas las carpetas `ConsolePort*` a `World of Warcraft/Interface/AddOns/` / Copy every `ConsolePort*` folder into `World of Warcraft/Interface/AddOns/`.
3. Usa [WoWpadX](https://github.com/leoaviana/WoWpadX) como controlador del mando / Use [WoWpadX](https://github.com/leoaviana/WoWpadX) as the controller driver.
